HTML General Practices

Code Name Description
<h1>This is an h1</h1> Element Content Content inside an opening and closing tag.
</element> Closing tag Is used to close an HTML element.
<p id="x" class="y"> HTML Attribute Attributes are used to add behaviors or configurations to opening tags.
<p>hello!</p> HTML Element Is an HTML tag.
<div> HTML Tag A syntax that defines an element in the document.
--<p> Indentation It's the recommended way to write nested HTML elements for ease of use.
<!--This is a comment--> Comment Adds context to code, does not render as content or change behavior.
<!DOCTYPE html> Document Type Declares the document type and prepares the file for HTML.

HTML Elements

Code Name Description
<li> List Element Creates an element inside an ordered or unordered list.
<em> Emphasis Element Emphazises the enclosed text and renders it in italics.
<ol><li></li></ol> Ordered List Encloses <li> elements to create numbered lists aka ordered lists.
<div>Content</div> Division Element It's used as an element that contains information and divides the document into sections.
<br> Line break Creates a line break when used within a body of text.
<h1><h6> Headings Adds six levels of hierarchy headings to organize content.
<p>This is text</p> Paragraph element Display a box of text.
<ul><li></li></ul> Unordered List Encloses <li> elements to create bulleted lists aka unordered lists.
<body>Content</body> Unordered List Renders content in an HTML document, only use one per file.
<p>This<span>text</span></p> Span Element Used to style inline text, not semantic.
<p>This is<strong>Bold</strong></p> Strong Element Highlights important text, renders it as bold.
<a href="...">link name</a> Anchor Element Creates clickable links to other elements, files or urls.
<head>Metadata stored here</head> Head Element Contains important information for the HTML file. not rendered visually
<html>all html elements</html> HTML Element Contains all the HTML information of a file.
<title>Page Title</title> Title Element Contains the page's title, displayed by the browser window or tab.

Semantic Elements

Code Name Description
<video src="...mp4" controls>... Video Element Embeds a media player for video playback.
<img src="...png"> Image Element Embeds an image with a source attribute, does not need a closing tag.
<embed src="..."/> Embed element Used to insert media, not recommended.
<figure><img src="..."></figure> Figure Element Used to encapsulate semantically image based media.
<figcaption>figure description...</figcaption> Figcaption Element Used to semantically describe the image inside a figure element.
<section>...!</section> Section Element Defines semantically an area within the file, can be used with article elements.
<article>...!</article> Article Element Used to contextualize information of a section.

Table Elements

Code Name Description
<tr>...</tr> Table Row Element Adds a table row to the table, contains data cells.
<td>Cell info</td> Table Data Element Nested inside a row, adds a cell with data inside.
<thead>...</thead> Table Header Defines Semantically the rows of a table that contains the heading information.
<tbody>...</tbody> Table Body Contains the content of the table semantically.
<th>Column header</th> Table Heading Contains the content of the table semantically.
<tfoot>...</tfoot> Table Footer Adds a section within the table defined as the footer, used for summaries.

HTML Attributes

Code Name Description
<h1 id="x"></h1> Unique ID Attribute Adds an unique identifier to an element, has high hierarchy in css.
<img alt="x"/> Alt Attribute Adds alternative text, helps accessibility and SEO.
<a href=... target="x">... Target Attribute Specifies where and how anchor hyperlinks should be opened
<a href="#Hey">Hey</a> Section Links Ask browser to navigate to correspondig file path.
<a href=".about">about</a> File Path Contains the content of the table semantically.
<th rowspan="x"> Rowspan Attribute Defines how many rows the cell should occupy.
<th colspan="x"> Colspan Attribute Defines how many columns the cell should occupy.
